# 搜尋演算法互動教室

一份以台灣繁體中文設計的互動式演算法教材，帶學生理解「循序搜尋」與「二元搜尋」。  
教材結合動畫模擬、實戰挑戰、Scratch 練習、作業檢查器與課後小測驗，適合用在國中資訊課、程式設計入門或演算法概念教學。

## 線上教材

[前往搜尋演算法互動教室](https://andrewkotw.github.io/binarysearch/)

## 特色

- **互動式搜尋動畫**：用視覺化方式呈現循序搜尋與二元搜尋的每一步。
- **單步與自動播放模式**：學生可以慢慢觀察，也可以快速看完整個流程。
- **二元搜尋指標顯示**：清楚標示 `L`、`M`、`H`，幫助理解搜尋範圍如何縮小。
- **猜數字遊戲**：把二元搜尋轉化成學生熟悉的範圍推理活動。
- **演算法比較與挑戰題**：練習判斷什麼情境該用循序搜尋或二元搜尋。
- **資料量成長模擬器**：用長條圖比較資料變多時兩種搜尋法的效率差異。
- **Scratch 練習支援**：提供半完成 `.sb3` 檔案下載與積木邏輯提示。
- **Scratch 作業檢查器**：學生可上傳 `.sb3` 檔案，檢查是否包含關鍵演算法結構。
- **隨機化小測驗**：題目與選項都會隨機排列，降低互相抄答案的機會。
- **Google 試算表紀錄**：可將成績與錯題題號上傳，方便老師分析學習狀況。

## 教材內容

### `index.html`

主頁是一個完整的互動學習流程：

1. 循序搜尋視覺化
2. 二元搜尋視覺化
3. 猜數字遊戲
4. 搜尋法比較表
5. 實戰挑戰
6. 資料量成長模擬器
7. Scratch 實作指南
8. Scratch `.sb3` 作業檢查器

學生可以先觀察演算法運作，再透過 Scratch 練習把概念轉成程式邏輯。

### `quiz.html`

小測驗包含 10 題選擇題，會隨機排列題目與選項。交卷後會立即顯示：

- 答對題數
- 答錯題數
- 得分比例
- 每題答案與解析
- 可複製、下載或列印的評量紀錄

如果設定 Google Apps Script Web App URL，測驗結果也會自動送到 Google 試算表。

## 錯題追蹤設計

雖然小測驗會隨機排列題目，但每一題都保留「原始題號」。

例如原本第 7 題出現在學生畫面的第 1 題，學生答錯時，Google 試算表仍會記錄為：

```text
[7]
```

這樣老師統計錯題時，看到的是原始題號，不會被隨機題序干擾。

## Google 試算表整合

測驗可透過 Apps Script 寫入 Google 試算表，紀錄欄位包含：

- 提交時間
- 測驗名稱
- 姓名
- 班級與座號
- 答對 / 答錯 / 總題數
- 得分比例
- 原始錯題題號

設定方式請參考 [apps-script-doc.md](./apps-script-doc.md)。

## 本機執行

這是純前端靜態網站，可以直接用瀏覽器開啟 `index.html`。

也可以用簡單的本機伺服器測試：

```bash
python3 -m http.server 8000
```

然後開啟：

```text
http://localhost:8000
```

## 教學目標

這份教材希望幫助學生：

- 理解循序搜尋「一筆一筆找」的概念
- 理解二元搜尋「每次排除一半」的策略
- 知道二元搜尋必須使用已排序資料
- 看懂 `L`、`M`、`H` 在搜尋過程中的變化
- 把演算法思考轉換成 Scratch 程式
- 透過測驗與錯題紀錄檢查學習成效
